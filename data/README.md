# Diretório de Dados (`data/`)

> **Aviso:** Não versionar os datasets brutos neste repositório.

## Instruções de Download

Adicione aqui as instruções para obter os dados necessários para o projeto:
1. Fonte dos dados (ex: link do Kaggle, repositório externo, dump de e-commerce, etc.).
2. Onde salvar os arquivos baixados (ex: salvar na pasta `data/raw/` ou `data/`).
3. Formato esperado dos arquivos (ex: `reviews.csv`, `products.json`).
